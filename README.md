# Rostos do Orbi Laboratório

Só desenhos: os rostos em pixel art dos personagens do Orbi Laboratório, um PNG de 256 × 256 por
rosto, usados como foto de quem fala no Slack. O nome de cada arquivo é o começo do SHA-256 do
próprio PNG; não há nomes, mensagens nem outros dados aqui.

Os arquivos são gerados e publicados pelo Orbi Laboratório (`src/rostos.mjs`,
`scripts/rostos.mjs`); não edite à mão.

## Créditos

- Personagens e guarda-roupa: [Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents),
  por Pablo De Lucca, licença MIT (`LICENSE-pixel-agents`). Os bonecos deles partem do
  [MetroCity](https://jik-a-4.itch.io/metrocity-free-topdown-character-pack), de JIK-A-4.
- Trajes temáticos (astronauta, chef, robô…): desenho da Orbi sobre as formas do Pixel Agents,
  com "Roguelike Characters", de Kenney (CC0 1.0), como referência visual.
